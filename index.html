Apa itu EXIF?

Exchangeable Image File Format adalah metadata yang tersimpan otomatis oleh kamera saat memotret: merek perangkat, waktu pengambilan, setting lensa, hingga lokasi GPS.

👻

Ghost Tag Xiaomi

Beberapa HP Android membuat folder GPS kosong di dalam foto meskipun lokasi tidak aktif — ini disebut "Ghost Tag". Geop.id pintar mendeteksi dan memfilter data hantu ini.

🛡️

Lindungi Privasi Anda

Sebelum membagikan foto ke internet, hapus metadata GPS terlebih dahulu. Foto di media sosial umumnya sudah otomatis di-strip, tetapi foto yang dikirim via email/WA asli bisa membocorkan rumah Anda.

🔍

Deteksi Manipulasi

Kamera asli menandai EXIF dengan nama model HP. Jika EXIF menyebutkan "Adobe Photoshop", "Snapseed", atau "VSCO", besar kemungkinan foto tersebut telah disunting.

Tentang Geop.id

Geop.id dibuat sebagai alat edukasi literasi digital dan bantuan investigasi forensik ringan. Semua pemrosesan dilakukan di perangkat Anda sendiri menggunakan JavaScript — file foto tidak pernah meninggalkan browser Anda.
